Hand-made vector figures required by main.tex
=============================================

Two figures must be created by the author in PowerPoint / Canva / Visio / draw.io
and exported as vector PDFs into THIS folder, following the journal guidelines
(white background, numbered coloured step circles, sub-steps in rectangles with
indices like 1.1/1.2, coloured arrows per level, icons + 2-3 word labels, no long
paragraphs, readable when printed; zoom in and pixels must not break).

1) workflow.pdf      -> referenced by Figure \label{fig:workflow}
   End-to-end pipeline: (1) dataset selection, (2) inspection, (3) crop
   extraction + cleaning, (4) leakage-free match-level split, (5) train-only
   balancing + augmentation, (6) model development (Custom CNN, MobileNetV2,
   ResNet50), (7) training (early stopping, checkpoint, class weights),
   (8) evaluation (accuracy, macro/per-class F1, confusion matrices),
   (9) Grad-CAM + SHAP + robustness, (10) practical interpretation.

2) architecture.pdf  -> referenced by Figure \label{fig:architecture}
   Custom CNN diagram: input 224x224x3 -> 4 conv blocks (32/64/128/256 filters,
   each Conv3x3 + BatchNorm + MaxPool2x2 + Dropout) -> GlobalAveragePooling ->
   Dense(256)+BN+Dropout -> Dense(4, softmax) producing ball/goalkeeper/player/
   referee probabilities.

The graphical abstract (frontmatter, \begin{graphicalabstract}) also still needs
to be produced and uncommented.

All other figures are auto-generated by the pipeline and live in ../outputs/.
